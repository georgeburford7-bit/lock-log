LOCK dashboard privacy policy

Last updated 21 October 2026.

What this is

LOCK dashboard is a private, single user tool built and used by one person for their own training log. It is not offered to the public and has no other users.

What data it reads

With the owner's permission through WHOOP's own sign in, it reads the owner's WHOOP recovery, sleep, daily strain and workout data. It does not read anyone else's data.

Where the data goes

The data is copied into the owner's own private Google Sheet and shown in the owner's own dashboard. It is not shared with, sold to or processed by any other party, and it is not used for advertising or analytics.

How it is protected

The WHOOP access credentials are stored only in the owner's private Google Apps Script settings and are never placed in a web page or a public file.

Keeping and deleting data

The owner can delete the data from their sheet at any time and can revoke the app's access from their WHOOP account, which stops all further reads.
